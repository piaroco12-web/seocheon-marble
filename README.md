# seocheon-marble
다 같이 돌자, 서천 한 바퀴 — 서천탐험대 체험 보드게임

금산판([geumsan-marble](https://github.com/piaroco12-web/geumsan-marble))과 같은 코드로 만든 서천판입니다. 게임 규칙·화면·미니게임 엔진은 그대로이고, `public/regions/seocheon/`의 데이터와 그림만 서천 것으로 바뀌었습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 배포용 파일
```

Vercel에 올릴 때는 Framework를 Vite로 두면 됩니다.

## 규칙 (금산판과 같음)

- 12턴, 하트 3개. 문제를 틀리거나 15초가 지나면 하트가 하나 줄어듭니다.
- 오늘의 도장 4곳(판마다 무작위)에서 문제를 맞혀 도장을 모으고 출발 칸으로 돌아오면 완주(+30점).
- 정답 +10점, 출발 칸을 지나면 +5점, 힌트 1번(틀린 보기 지우기), 서천 버스 3번(도장 장소로 바로 이동).
- 찬스 칸: 점수·버스표·하트·2칸 앞으로·깜짝 퀴즈·깜짝 미니게임 중 하나. 쉼터: 하트 1개 회복과 서천 이야기 카드.

## 서천판 구성

- 출발: 한산모시문화제 마당 · 쉼터: 춘장대 솔밭 쉼터 · 찬스: 모시 실꾸리 바구니
- 장소 10곳: 한산모시관, 문헌서원, 이상재 선생 생가지, 신성리 갈대밭, 금강하구 조류생태전시관, 서천갯벌 유부도, 국립생태원 에코리움, 장항스카이워크, 홍원항, 마량리 동백나무숲
- 안내 캐릭터: 서아, 천이 · 말: 모시 요정, 동백이, 검은머리물떼새, 주꾸미

## 미니게임

`board.json`에서 장소의 `mode`가 `quiz_or_minigame`이면 절반 확률로 미니게임이 나옵니다. 성공하면 +15점과 도장, 실패해도 하트는 줄지 않습니다. 첫 화면의 **🎮 미니게임만 해 보기**로 따로 연습할 수 있습니다.

| 미니게임 | 장소 | 방식 |
|---|---|---|
| 모시 올 뽑기 (`ramie`) | 한산모시관 | 바늘이 초록 칸에 올 때 뽑기, 3번 성공 |
| 서천 생태 짝 맞추기 (`memory`) | 국립생태원 에코리움 | 카드 8장 짝 찾기 (쉬움 45초 · 보통 32초) |
| 철새 길 안내 (`bird`) | 금강하구 조류생태전시관 | 화살표 명령을 순서대로 넣어 전봇대를 피해 갯벌 먹이터까지 (순차 명령, 기회 3번) |

## 퀴즈

저학년 31문항 · 고학년 30문항, 모두 61문항입니다. 분류는 `specialty` `history` `people` `nature` `environment` `society` `safety`.

문항을 더 넣거나 고칠 때 지킬 것:

- **`type: "choice"`의 `answer`는 항상 `0`** — 게임이 보기 순서를 매번 섞습니다(`src/main.js`의 `shuffle`). 정답을 첫 보기에 두면 됩니다.
- `type: "ox"`는 `choices`가 `["O","X"]`이고 순서를 섞지 않습니다. 참이면 `answer: 0`, 거짓이면 `1`.
- `places`는 `board.json`의 장소 키를 씁니다.
- 문항에 `"image": "photos/파일명.jpg"`를 더하면 문제 위에 사진이 나옵니다.

`verified: false`인 두 문항(H04, H28)은 공식 자료로 확인한 뒤 `true`로 바꿔 주세요.

### 내용을 고칠 때 주의

- **목은 이색의 출생지를 한산으로 쓰지 마세요.** 이색은 외가인 영덕에서 태어났다고 보는 자료가 있습니다. 한산은 본관(한산 이씨 중시조)이자 생활 근거지입니다. 그래서 출생지를 묻는 문항은 넣지 않았습니다.
- **한산소곡주는 장소 칸에 넣지 않았습니다.** 초등 대상이라 전통 술을 칸으로 두지 않고, 무형유산 설명으로 `facts.json`에만 담았습니다.
- 장항스카이워크 길이(236m·250m), 마량리 동백나무 그루 수(70~85그루)는 자료가 엇갈려 문항에 쓰지 않았습니다.

## 오프라인 설치

배포된 주소를 한 번 열면 게임 파일과 `board.json`에 적힌 그림을 기기에 저장합니다(`public/sw.js`). 그 뒤에는 인터넷이 없어도 실행되고, 크롬·엣지에서 "앱 설치"로 바탕화면에 둘 수 있습니다. 개발 서버(`npm run dev`)에서는 꺼져 있습니다.

저장 이름(`seocheon-marble-v1`), 설정 키(`seocheon-marble-settings`), 소리 설정 키(`seocheon-audio-enabled`)는 금산판·보령판과 겹치지 않게 지역 이름을 붙여 두었습니다. 같은 주소에 여러 지역판을 올려도 서로 설정을 덮어쓰지 않습니다.

### 화면 색을 서천답게 바꾸고 싶다면

`src/style.css`의 `:root` 색 토큰은 **의미가 묶여 있어** 손대지 않았습니다. `--berry`는 주 버튼·주사위·도장 색이고 377·459줄에 붉은 계열 그라데이션이 하드코딩으로 짝지어져 있으며, `--leaf`는 정답·성공 색입니다. 서천은 동백 붉은빛(`#c62b2b`)이 `--berry`와 가까워 바꾸기가 쉬운 편입니다.

| 고칠 곳 | 내용 |
|---|---|
| `:root` | `--ivory` `#e8e3d3` · `--berry` `#c62b2b` · `--berry-dark` `#951f1f` · `--leaf` `#35704a` · `--rust` `#c9a24a` · `--bg-deep` `#1e2a1e` |
| `body` 배경 | `#6b4422` → `#3b5a3a` |
| 377·459줄 | `#ef6c57`, `#f06e59` 를 `--berry`와 어울리는 색으로 |
| 51·387줄 | `#fff4d6`, `#c99a5a` 를 `--ivory`와 어울리는 색으로 |

바꾼 뒤에는 정답(초록)·오답(붉은색) 구분이 또렷한지 꼭 눈으로 확인하세요.
